## 👨‍💻 Entre um SELECT e um endpoint…

Sou **Analista de Integração**, no Brasil. Meu dia a dia passa por **Oracle, SQL, PL/SQL e APIs REST**, conectando sistemas e dados.

Quando a ideia precisa ganhar uma tela, entram **PHP, JavaScript, HTML e CSS**. Minha atuação passa por essa ponte entre a aplicação que a pessoa usa e os sistemas que fazem tudo acontecer por trás.

## 🚀 Coisas que saíram do editor

### 🏥 Totem PA · Unimed Blumenau

**Do toque na tela à integração com o Tasy.**

Aplicação de autoatendimento para o Pronto Atendimento da Unimed Blumenau. Atuei tanto no **desenvolvimento da aplicação web** quanto na **integração com Tasy/Oracle**.

<details>
<summary><b>🔎 Abrir o fluxo de autoatendimento</b></summary>

1. O beneficiário se identifica com carteirinha ou CPF.
2. Atualiza seus dados cadastrais.
3. Seleciona o tipo de atendimento e registra um acompanhante.
4. Aceita o termo e recebe a senha de atendimento.

**Por trás da tela:** PHP · HTML · CSS · JavaScript · Oracle/Tasy

</details>
