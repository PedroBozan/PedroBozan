## 🚀 Projetos em destaque

### 🖥️ Totem PA — Unimed Blumenau
Aplicação de autoatendimento (totem) para o Pronto Atendimento da Unimed Blumenau. Atuei tanto no **desenvolvimento da aplicação** (PHP, HTML, CSS, JavaScript) quanto na **integração com o sistema Tasy/Oracle**.

**Principais funcionalidades:**
- Identificação do beneficiário via carteirinha/CPF
- Atualização cadastral do beneficiário
- Seleção do tipo de atendimento e registro de acompanhante
- Aceite de termo e emissão de senha de atendimento

**Tecnologias:** PHP · HTML · CSS · JavaScript · Oracle/Tasy
