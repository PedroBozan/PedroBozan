## 🚀 Projetos em destaque

### Totem PA — Unimed Blumenau

Aplicação de autoatendimento para o Pronto Atendimento da Unimed Blumenau. Atuei no **desenvolvimento da aplicação web** e na **integração com o sistema Tasy e o banco de dados Oracle**.

O fluxo de autoatendimento inclui:

- Identificação do beneficiário por carteirinha ou CPF.
- Atualização dos dados cadastrais.
- Seleção do tipo de atendimento e registro de acompanhante.
- Aceite de termo e emissão de senha de atendimento.

**Tecnologias:** PHP · HTML · CSS · JavaScript · Oracle · Tasy

### [consulta-cep](https://github.com/PedroBozan/consulta-cep)

**Tecnologia:** PHP · **Integração:** API ViaCEP
